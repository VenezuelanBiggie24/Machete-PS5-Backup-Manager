## The Performance & Stability Update
This is a massive under-the-hood update focusing on critical performance optimizations, stability, and cross-platform compatibility.

### 🚀 Performance & UI Improvements
* **Isolated Transfer Progress:** Fixed a critical bug where the entire file grid would re-render 10 times a second during transfers. The Cyberpunk progress UI is now fully isolated, resulting in 0% UI lag even with hundreds of loaded games.
* **Instantaneous Speed Tracking:** The transfer speed (MB/s) now measures accurate instantaneous windows (100ms delta) instead of a lifetime average, providing true real-time read/write speeds.
* **IPC Channel Chunking:** Resolves Tauri backend flooding. Metadata API requests to SerialStation are now chunked in batches of 5, preventing the application from freezing when loading massive 2TB hard drives.
* **Asynchronous Directory Loading:** Removed a synchronous bottleneck that calculated deep folder sizes on the main thread. Large folders will no longer freeze the app on initial load.

### 🛡️ Security & Stability
* **Data Corruption Prevention:** Fixed an issue where the `machete_custom_meta.json` database would silently fail or overwrite itself if it was temporarily locked by Windows Defender. The system now strictly propagates file `Result` errors.
* **Strict CSP Enabled:** Enforced a strict Content Security Policy to prevent arbitrary execution.
* **Tauri Scopes Enforced:** Completely removed the unused `@tauri-apps/plugin-fs`. All file operations are now strictly handled by our custom, validated Rust IPC commands, reducing the attack surface.
* **Race Condition Fixes:** Repaired stale closures in React's state management. Quickly deleting multiple files or switching directories will no longer cause ghost items to reappear.

### 🛠️ Packaging & Compatibility
* **Universal macOS Support:** The macOS application is now built as a Universal Binary. It runs natively and flawlessly on both Apple Silicon (M1/M2/M3) and Intel (x86_64) Macs.
* **Binary Bloat Reduction:** Enabled advanced Rust compilation profiles (`lto = true`, `opt-level = "s"`, `strip = true`). The application executables are now incredibly lightweight.
* **Linux Icon Fix:** Registered missing Linux icons in the builder, resolving issues where `.deb` and `.AppImage` packages lacked the proper Machete logo on Ubuntu and Arch systems.
* **Windows Drive Detection:** Patched case-insensitive edge cases for Windows drive letters (`C:\` vs `c:\`), ensuring accurate available disk space calculations.

## La Actualización de Rendimiento y Estabilidad
Esta es una actualización masiva del motor interno enfocada en optimizar drásticamente el rendimiento, la estabilidad y la compatibilidad en todas las plataformas.

### 🚀 Mejoras de Rendimiento y UI
* **Progreso de Transferencia Aislado:** Se corrigió un error crítico donde toda la cuadrícula de juegos se volvía a dibujar 10 veces por segundo durante las transferencias. La interfaz Cyberpunk ahora es un componente aislado, eliminando por completo el lag en la app.
* **Velocidad Instantánea Real:** La velocidad de transferencia (MB/s) ahora se calcula de manera instantánea (en ventanas de 100ms) en lugar de dar un promedio histórico, mostrando la velocidad real de lectura/escritura de tu disco.
* **Chunking de Peticiones IPC:** Se resolvió el ahogo del backend de Tauri. Las peticiones a SerialStation ahora viajan en paquetes de 5 (chunking), evitando que la app se congele al escanear discos duros de 2TB con cientos de juegos.
* **Lectura de Directorios Asíncrona:** Se eliminó un cuello de botella que sumaba el tamaño de las carpetas de manera sincrónica. Las carpetas pesadas ya no congelarán la app al cargar.

### 🛡️ Seguridad y Estabilidad
* **Prevención de Corrupción de Datos:** Se arregló un problema donde la base de datos `machete_custom_meta.json` fallaba en silencio o se borraba si Windows Defender la bloqueaba temporalmente. Ahora el sistema maneja y propaga los errores correctamente.
* **Política CSP Estricta:** Se habilitó un Content Security Policy estricto para bloquear la ejecución de código no deseado.
* **Menor Superficie de Ataque:** Se eliminó por completo el plugin `@tauri-apps/plugin-fs` innecesario. Todas las operaciones de archivos ahora pasan por nuestros comandos blindados en Rust.
* **Reparación de Race Conditions:** Se arreglaron cruces de estado en React. Borrar juegos rápidamente o cambiar de disco ya no hará que reaparezcan juegos fantasma.

### 🛠️ Empaquetado y Compatibilidad
* **Soporte Universal en macOS:** La aplicación para Mac ahora es un Binario Universal. Corre de forma nativa e impecable tanto en Apple Silicon (M1/M2/M3) como en procesadores Intel.
* **Reducción Extrema de Tamaño:** Se activaron perfiles avanzados de compilación en Rust (`lto = true`, `opt-level = "s"`, `strip = true`). Los ejecutables ahora pesan una fracción de su tamaño original.
* **Fix de Íconos en Linux:** Se registraron los íconos de Linux faltantes en el empaquetador, solucionando el problema donde los instaladores `.deb` y `.AppImage` no mostraban el logo de Machete.
* **Detección de Discos en Windows:** Se parcheó el reconocimiento de mayúsculas/minúsculas en las letras de los discos en Windows (`C:\` vs `c:\`), garantizando que el cálculo de espacio libre funcione siempre.
