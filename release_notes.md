# v1.2.0

### Changelog / Novedades
* **Transferencias Nativas:** Soporte para mover archivos y carpetas usando Drag & Drop o haciendo click en la Dropzone para abrir el explorador de archivos.
* **Progreso en Tiempo Real:** Nueva UI con barra de progreso que calcula y muestra la velocidad de transferencia (MB/s) y el tiempo estimado (ETA).
* **Corrección de Cuadrícula:** Ajuste matemático del padding del CSS Grid para el alineamiento perfecto de las máscaras de recorte en capturas.
