### Changelog / Novedades (v1.1.0)

🇬🇧 **English**
* **Custom Support:** Ability to assign custom covers and titles using the local database.
* **Improved UI:** Increased default window size to comfortably fit the entire grid.
* **SSD Warning:** Added loading time warnings for scanning high-capacity drives.
* **Internationalization:** 100% full translation of UI and modals.

🇻🇪 **Español**
* **Soporte Personalizado:** Posibilidad de asignar carátulas y títulos personalizados usando la base de datos local.
* **UI Mejorada:** Mayor tamaño de ventana por defecto para visualizar toda la cuadrícula cómodamente.
* **Aviso de SSD:** Alerta de tiempos de carga añadida para escaneos en discos de alta capacidad.
* **Internacionalización:** Traducción total al 100% de la UI y modales.
