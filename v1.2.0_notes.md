### Changelog / Novedades (v1.2.0)

🇬🇧 **English**
* **Native Transfers:** Added Drag & Drop support and click-to-open system file picker for transferring files and folders.
* **Real-time Progress:** New UI overlay featuring a progress bar, live transfer speed (MB/s), and Estimated Time of Arrival (ETA).
* **Grid Correction:** Mathematically adjusted CSS Grid padding for perfect alignment of cover crop masks.

🇻🇪 **Español**
* **Transferencias Nativas:** Añadido soporte Drag & Drop y click para abrir el explorador nativo y transferir archivos/carpetas.
* **Progreso en Tiempo Real:** Nueva UI con barra de progreso, velocidad en vivo (MB/s) y tiempo estimado (ETA).
* **Corrección de Cuadrícula:** Ajuste del padding del CSS Grid para el alineamiento perfecto de las máscaras de las carátulas.
